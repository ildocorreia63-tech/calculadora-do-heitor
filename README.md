# Calculadora do Heitor

Aplicativo responsivo com calculadora básica, tabuada de 1 a 20, desafios com pontuação e níveis, efeitos sonoros configuráveis, escolha de imagem de fundo e suporte PWA.

## Executar
Abra `index.html` em um navegador ou publique este repositório na Vercel como site estático. Não é necessário comando de build; use a pasta raiz.
